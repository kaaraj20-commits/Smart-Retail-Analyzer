# 📊 Smart Retail Sales & Business Intelligence Analyzer

## 📌 Project Overview

The Smart Retail Sales & Business Intelligence Analyzer is a Python-based data analysis project designed to analyze retail sales data and provide meaningful business insights through an interactive dashboard.

The project uses data cleaning, exploratory data analysis (EDA), and data visualization to understand sales performance, profitability, regional trends, product categories, and customer segments.

An interactive dashboard built using Streamlit allows users to explore the dataset through different filters.

## 🎯 Project Objectives

* Analyze overall retail sales and profit.
* Identify top-performing product categories.
* Compare sales performance across different regions.
* Analyze monthly sales trends.
* Identify profitable and loss-making sub-categories.
* Understand customer segment performance.
* Present business insights through an interactive dashboard.

## ✨ Key Features

* Data cleaning and preprocessing.
* Exploratory Data Analysis (EDA).
* Key Performance Indicators (KPIs).
* Category-wise sales and profit analysis.
* Region-wise sales and profit analysis.

## 🚀 Installation and Execution

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Step 2: Open the Project Folder

```bash
cd Smart_Retail_Analyzer
```

### Step 3: Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn streamlit
```

### Step 4: Run the Streamlit Dashboard

```bash
python -m streamlit run app.py
```

The dashboard will open in your default web browser.
